# Kanban Board

A simple Kanban board app built with React. Create boards, organize work into columns, and add, edit, or delete tasks. Board data is saved in your browser's local storage.

## Run the project

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

## What I learned as a beginner

- How to split a React app into small, reusable components.
- How to share app data with React Context and update it with state.
- How to build forms and handle user actions such as creating, editing, and deleting boards and tasks.
- How to save data in local storage so it stays after refreshing the page.
- How to style an interface with Tailwind CSS.
- How to use dialogs, dropdowns, and drag-and-drop tools in a React project.
